How it works

No uploads, no notebooks to configure. Lists in, code out.

Paste the header

A header row, or a few rows of your CSV or spreadsheet. Types and roles are guessed: date → time t, sales → target y.

Mark what matters

One click per column for its role, a ★ for your key drivers, a tick for drivers you know in advance. Drag a point on a simplex to trade accuracy, interpretability and speed.

Run the code

Pick from the ranked models and copy train.py, predict.py and requirements.txt. They load your CSV, build the features, validate honestly, and save a model you can use.

Questions

Is there a limit to what machine learning can do in my industry?
Does RoboIntern run my data or train anything?

No. It’s a lookup dictionary with a code writer. Parsing happens in your browser; you run the Python on your own machine, where your data already is.

What do you store?

Only what you save: listing titles, notes, the code, and the column names, types and roles of your data description. Never the values in your table.

Which libraries does the code use?

pandas and scikit-learn throughout, plus XGBoost, LightGBM, CatBoost, statsmodels, Prophet or PyTorch when the model needs them. requirements.txt lists exactly what to install.

Is the generated code any good?

It is careful where it counts: time-ordered splits, a seasonal-naïve benchmark, MASE, lags that never peek at the future, conformal intervals and permutation importance. Every model’s listing is run end to end on test data before release. It is still a starting point: read it and tune it.

Is it free?

Yes. The Atlas, the Lab and the code are free without an account. A free account adds your notebook and the Commons.
